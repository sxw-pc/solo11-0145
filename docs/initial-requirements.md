# 初始需求与边界

本版交付三套独立证据账：设备与泊位状态、闸机车次、临占许可。原始事件以唯一 ID 和 SHA-256 留存，投影可重算；余位报告存其依赖状态和时间。核心业务决定包括设备是否可信、乱序时占位归并、断联未知、进出配对、跨夜时段、重复回执、许可优先级、临占并集、差额责任及可计费时段。

三条跨账路径必须产生不同结论：地磁失效且闸机完整时给保守上限，若同时有孤立出场则变为 unknown；孤立出场不能虚增余位，已知地磁与闸机差异冻结发布；临占撤销只恢复总容量，闸机差额仍冻结。上述结果由 fixture 与测试从原始事件重算。

尚未实现：业主共享泊位时段、充电枪故障联动、预测误差审计、事故封场广播、跨场库诱导分流、传感漂移校准工单、匿名车牌跨闸机归并。这些各需要新的业务对象或证据账；不应把本版结果误称为这些能力。

离线停车费裁定已独立交付（见 `src/parking/billing.py`）：闸机事件携带闸机身份并接收按闸机生效的共同校时偏移区间，同闸机进出共用偏移、跨闸机偏移独立，按全部可行组合枚举真实时长与整数分金额；费率支持免费宽限、跨档起算、每日封顶与 UTC 跨零点分段；精确出账与保底预收两类合同分别给出待核、正式账单、预收凭证、补收与退回决定，原始闸机事件与已出账单只追加不改写。
