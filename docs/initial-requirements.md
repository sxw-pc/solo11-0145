# 初始需求与边界

本版交付三套独立证据账：设备与泊位状态、闸机车次、临占许可。原始事件以唯一 ID 和 SHA-256 留存，投影可重算；余位报告存其依赖状态和时间。核心业务决定包括设备是否可信、乱序时占位归并、断联未知、进出配对、跨夜时段、重复回执、许可优先级、临占并集、差额责任及可计费时段。

三条跨账路径必须产生不同结论：地磁失效且闸机完整时给保守上限，若同时有孤立出场则变为 unknown；孤立出场不能虚增余位，已知地磁与闸机差异冻结发布；临占撤销只恢复总容量，闸机差额仍冻结。上述结果由 fixture 与测试从原始事件重算。

尚未实现：业主共享泊位时段、充电枪故障联动、预测误差审计、事故封场广播、跨场库诱导分流、传感漂移校准工单、匿名车牌跨闸机归并、计费争议取证。这些各需要新的业务对象或证据账；不应把本版结果误称为这些能力。

## 无障碍占用核查边界

无障碍许可、凭证核验、现场刷证与人工观察构成第四套证据账，入口为 `accessible-audit`。它只回答“某段无障碍车位占用是否获得授权、是否必须现场巡查、能否指向具体匿名 stay”，不改变普通余位与计费。地磁是唯一占位来源；闸机与刷证只约束匿名 stay 的归属。结论按完整可行归属逐一举证，只有每种归属都无有效许可才判无授权；车位违规与车主身份是分开的结论。普通车位的无关占用不进入该模型。许可撤销、版次变化、刷证或人工核验只追加新核查版本。
